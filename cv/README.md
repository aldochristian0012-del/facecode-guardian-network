## 🔧 Compilación

### Requisitos

```bash
# Ubuntu/Debian
sudo apt-get install texlive-latex-extra texlive-fonts-recommended

# macOS (con Homebrew)
brew install --cask mactex
```

### Compilar PDF

```bash
cd cv/
xelatex christian-patino-cv.tex
xelatex christian-patino-cv.tex  # ejecutar dos veces para formato correcto
```

El PDF se generará como `christian-patino-cv.pdf`.
