## VARIANTE B: "Transparencia Técnica" (Énfasis en cómo funciona)

**Título:** ⚙️ Cómo protegemos tu privacidad

**Subtítulo:** Tecnología explicada en lenguaje humano

**Cuerpo (189 palabras):**

FaceCode® convierte características únicas de tu rostro en un **template matemático** (vector de 128-512 dimensiones) que funciona como una huella digital, pero para tu cara.

**¿Qué NO almacenamos?**
- ❌ Fotos de tu rostro
- ❌ Videos
- ❌ Imágenes identificables

**¿Qué SÍ generamos?**
- ✅ Un vector numérico irreversible (no se puede reconstruir tu foto)
- ✅ Procesado en tu dispositivo (iPhone CoreML, Android ML Kit)
- ✅ Eliminado automáticamente en 24 horas

**El flujo técnico:**
1. Tu cámara captura tu rostro → 2. El algoritmo extrae patrones matemáticos → 3. Se genera un FaceCode® → 4. Se elimina la imagen → 5. Solo queda el template cifrado

**Seguridad:**
- Cifrado AES-256 en reposo
- TLS 1.3 en tránsito
- Procesamiento on-device preferente
- Guardian Nodes monitoreando uso ético en tiempo real

**Tus derechos:**
Accede, corrige o elimina tus datos en **Ajustes → Privacidad → Solicitud ARCO**. Tiempo de respuesta: máximo 20 días hábiles.

**¿Dudas?** Escribe a privacy@facecode.app o consulta la [Política de Privacidad completa].

**Botón primario:** "Entendido, continuar"
**Link secundario:** "Ver diagrama técnico"

"Consiento el tratamiento de mis datos biométricos conforme a la LFPDPPP 2025. [Más info]"

## RECOMENDACIONES PARA A/B TESTING

### Hipótesis de testing

**H1:** La Variante A aumentará la tasa de aceptación en usuarios preocupados por privacidad (segmento privacy-conscious).
**H2:** La Variante B generará mayor confianza en usuarios técnicos (developers, early adopters).
**H3:** La Variante C resonará con usuarios Gen Z/Millennials preocupados por derechos digitales.

### Métricas clave (KPIs)

1. **Acceptance rate:** % de usuarios que aceptan vs. abandonan
2. **Time to decision:** Segundos entre mostrar el aviso y la aceptación
3. **Click on "Learn more":** % que hace clic en política completa
4. **Settings engagement:** % que entra a Ajustes → Privacidad post-onboarding
5. **Revocation rate:** % que revoca consentimiento en primeras 48 horas

### Distribución sugerida

- **Semana 1-2:** 70% Control (versión actual) / 10% A / 10% B / 10% C
- **Semana 3-4:** 40% Control / 20% A / 20% B / 20% C
- **Semana 5+:** 100% de la variante ganadora

### Segmentación

| Segmento | Variante recomendada |
|----------|---------------------|
| Usuarios de iOS | Variante B (aprecian transparencia técnica) |
| Usuarios de Android | Variante A (énfasis en seguridad) |
| Early adopters / Beta testers | Variante B (quieren entender el "cómo") |
| Usuarios +45 años | Variante A (simplicidad y garantías) |
| Usuarios 18-35 años | Variante C (control y derechos) |
| Europa / GDPR-aware | Variante A (privacidad radical) |
| Latinoamérica | Variante C (derechos y transparencia) |

## IMPLEMENTACIÓN TÉCNICA (UI/UX)

### Flujo recomendado (Just-in-Time Consent)

```
1. Usuario abre app por primera vez
   ↓
2. Pantalla de bienvenida (features, no menciona privacidad aún)
   ↓
3. Usuario intenta usar función de reconocimiento facial
   ↓
4. Modal de privacidad (Variante A/B/C según A/B test)
   ↓
5. Usuario lee y acepta → registra consentimiento
   ↓
6. Confirmación visual + icono de privacidad en status bar
   ↓
7. Función de reconocimiento facial habilitada
```

### Diseño del modal de consentimiento

**Características:**
- Scroll obligatorio (no se habilita botón "Aceptar" hasta ver todo el texto)
- Checkbox explícito (no pre-marcado)
- Link "Leer política completa" abre webview interno
- Botón secundario "Configurar privacidad avanzada" lleva a Ajustes
- Footer con versión de ToS: "Política v2025-10-29"

**Diseño visual:**
- Fondo semi-transparente con blur
- Card central con border radius 16px
- Iconos emojis para escaneabilidad
- Texto en San Francisco (iOS) / Roboto (Android)
- Tamaño de fuente: 16px (body), 20px (títulos)
- Contraste WCAG AAA para accesibilidad

### Accesibilidad (WCAG 2.1 AAA + EAA)

- ✅ Screen reader compatible (VoiceOver, TalkBack)
- ✅ Contraste mínimo 7:1 (AAA)
- ✅ Navegación por teclado/switch control
- ✅ Texto escalable hasta 200% sin pérdida de funcionalidad
- ✅ Alternativas textuales para iconos
- ✅ Tiempo ilimitado para leer (sin auto-dismiss)
