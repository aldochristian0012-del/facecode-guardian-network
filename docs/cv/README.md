## 🔧 Compilation Instructions

### Requirements
- TeX Live or MiKTeX distribution
- `moderncv` LaTeX package
- `xelatex` or `pdflatex` compiler

### Compile Commands

```bash
cd docs/cv
xelatex christian-patino-cv.tex
xelatex christian-patino-cv.tex  # Run twice for proper spacing
```

Alternatively, using pdflatex:
```bash
pdflatex christian-patino-cv.tex
pdflatex christian-patino-cv.tex
```

### Online Compilation
Upload `christian-patino-cv.tex` to [Overleaf](https://www.overleaf.com) for online compilation.
